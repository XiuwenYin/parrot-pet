# 鹦鹉桌宠 🦜

一只住在桌面上的牡丹鹦鹉。卡通形象和真实形象可以切换，鸟种也能换。

## 安装（给不用代码的朋友）

到本仓库的 **Releases** 页面下载安装包：

- Mac（Apple 芯片：M1/M2/M3/M4…）：`ParrotPet-版本-mac-arm64.dmg`
- Mac（Intel 芯片）：`ParrotPet-版本-mac-x64.dmg`
- Windows：`ParrotPet-版本-win-x64.exe`

第一次打开：
- **Mac**：安装包没有苹果开发者签名，打开时如果提示"无法验证开发者"或"已损坏"，
  到 系统设置 → 隐私与安全性，点"仍要打开"；或者在终端运行 `xattr -cr /Applications/鹦鹉桌宠.app` 再打开。
- **Windows**：如果出现"Windows 已保护你的电脑"，点"更多信息" → "仍要运行"。
- Windows 版暂不支持啃桌面图标（用到了 macOS 的系统能力）；视频/照片自动抠图 Mac 和 Windows 都支持。

## 从源码运行

```bash
cd parrot_pet
npm install
npm start
```

菜单栏会出现一个小鸟图标；右键点鸟，或者点菜单栏图标，都能打开菜单。

## 发布新版本

改好 `package.json` 里的 `version`，然后：

```bash
git tag v0.1.1 && git push origin v0.1.1
```

GitHub 会自动在 Mac 和 Windows 上打包，安装包出现在 Releases 页面（`.github/workflows/release.yml`）。
本机也能打 Mac 包：`npm run dist:mac`。

| 玩法 | 怎么触发 |
|---|---|

| 跳舞 | 双击 |
| 炸毛 | 2.5 秒内连点 5 下 |
| 被摸开心 | 鼠标在它头上来回蹭 |
| 叫醒 | 睡觉时点它 |

## 啃桌面图标

右键 → 做个动作 → 啃桌面图标（它自己偶尔也会去啃）。鸟会飞到一个**没被窗口挡住**的桌面图标旁边，
悬停着一口一口啃，图标边上留下锯齿咬痕和牙印，下面撒一地纸屑。

- **只是画出来的效果**：咬痕画在一层透明窗口上，不会碰到任何真实文件。
- 图标被窗口盖住时，咬痕跟着隐藏；图标被拖走，咬痕跟着走；15 分钟后自动淡掉。
  右键 → 打扫咬痕和纸屑 可以立刻清掉。
- 图标位置优先用"辅助功能"接口读（最准，桌面开着"自动排列"也对）：第一次会弹授权提示，
  在 系统设置 → 隐私与安全性 → 辅助功能 里允许鹦鹉桌宠。
  没给这个权限时退回问访达（会问"是否允许控制访达"），但桌面开着自动排列时访达给的位置不准，这时就不啃不爬。
- **爬桌面图标**：飞到一个图标顶上站着，上面同一列还有图标就用嘴勾、脚蹬一个个往上爬；图标被窗口挡住就不爬。
- 收在"叠放"里的文件没有单独的图标位置，不会被啃。

到了晚上 23 点到早上 7 点，或者你 5 分钟没理它，它会更爱睡觉。

## 名字、学说话、好奇心

- 右键 → **名字**：告诉它你叫什么、给这只鸟起名字。打招呼、学舌时会喊你的名字。
- 右键 → **教它说一句话**（会说话的鸟才有）：它先跟着念一遍，以后学舌时也会说。非洲灰会直接用语音说出来。
- **好奇心**：鼠标在它附近停住不动，它会走过去歪头研究、啄一下；桌面上多了个新文件，它会飞过去站上面看看。
- **听到音乐**（Mac）：电脑在放歌或视频时，凤头会蹦迪甩头、偶尔跟着大喊；别的鸟也会跟着点点头。
  只检测"有没有程序在放声音"，不录音、不读内容。

## 鸟种和习性

右键 → 鸟种，按家族分组，每个家族有几个常见颜色。不同鹦鹉不只是长得不一样，**习性也不一样**：

| | 外形 | 专属动作 | 被拎太久 | 叫声 |
|---|---|---|---|---|
| 牡丹（桃脸、蓝桃脸、黄桃脸、费氏、黄领、蓝牡丹） | 圆滚滚、短尾 | 撕纸条插尾巴、倒挂 | 狠咬一口（飞天老虎钳） | 尖细的"啾" |
| 虎皮（绿、蓝、黄化、金彩显） | 苗条长尾、头背波浪纹、蜡膜、喉斑 | 照镜子、学说话、点头 | 轻轻啄一下 | 叽叽喳喳碎碎念 |
| 玄凤（原始灰、黄化、白面） | 冠羽、橙色腮斑、长尾 | 吹口哨（照着真玄凤录音扒的"玄凤国歌叽咕叽"等两首）、心形翅膀、低头讨挠、夜里偶尔夜惊；冠羽随心情竖起/放下 | 冠羽全竖、嘶嘶哈气 | 婉转口哨 |
| 和尚（绿、蓝） | 灰脸灰胸带鳞片纹、长尾 | 叼树枝搭窝、说人话最多、和尚抖、用脚抓着吃 | 咬一口 | 嘎嘎大嗓门 |
| 凤头（葵花凤头） | 通体白、黄冠羽平时像一根蒜苗，激动才炸开 | 听歌蹦迪甩头、大喊大叫、用脚抓着吃、低头讨挠 | 轻轻啄一下 | 沙哑大嗓门 |
| 凯克（白腹、黑头） | 矮壮、白肚子、黄大腿 | 挺胸抬腿踢正步、用脚抓着吃 | 咬一口 | 尖细的哨音 |
| 非洲灰 | 灰色鳞片纹、白脸皮、浅黄眼睛、大红尾巴 | 学说话（真的说出来）、站在图标上念出图标名字、模仿手机铃声/微波炉/门铃 | 轻轻啄一下 | 低沉口哨 |

**叫声**：牡丹、虎皮、玄凤、和尚、凤头、非洲灰用的是真鸟录音剪出来的短片段（来自维基共享资源和 Freesound 的开放许可录音，
出处和许可见 [`assets/sounds/CREDITS.md`](assets/sounds/CREDITS.md)）；凯克没找到可用的录音，借和尚的叫声调高音调。
想换成自己找的录音：放进素材文件夹的 `sounds/<家族>/`（如 `sounds/cockatoo/`，文件名带 `screech` 的用作尖叫），
有的话整个替换掉自带的那一组；这个文件夹不进仓库。

**豆豆眼**：右键菜单勾选"豆豆眼"，眼睛换成没有高光的一颗小黑豆。
学舌说话用系统语音合成后加"鹦鹉嗓"处理（提高音调、削掉低频人声、加沙哑颤动），全在本机完成。

随机做动作的偏好也按习性来，比如虎皮话多、玄凤爱吹口哨、牡丹爱折腾纸。

加新鹦鹉：在 `src/parrot.js` 的 `SHAPES` 里加外形参数，在 `src/catalog.js` 里加 `FAMILIES`（习性）和 `SPECIES`（颜色品系）。

## 真实形象：直接丢视频、照片进去

1. 右键 → 真实素材 → **打开素材文件夹**，把鸟的视频或照片丢进去。
   丢在根目录 = 归到当前鸟种；丢进 `桃脸牡丹` 对应的 `roseicollis/` 等目录 = 归到那个鸟种。
2. 第一次用会提示下载自动抠图工具（右键 → 真实素材 → 下载自动抠图工具，只需一次）。
   Mac 约 60MB；Windows 约 150MB（会顺带下载一个独立的 Python，放在桌宠自己的数据目录 `%APPDATA%\parrot-pet` 里，不影响电脑上别的软件）。
3. 桌宠自己在后台处理，气泡会报进度和结果；处理完右键 → 形象 → 真实 就能看到。

它是怎么处理的：
- **找鸟**：在画面里找"最像鸟"的区域。Mac（macOS 14+）用系统自带的图像识别；
  Windows 和更老的 Mac 用 MobileNetV3 分类模型（ImageNet-21k，认得各种鹦鹉，也认得人、笼子）；
- **抠鸟**：用 MobileSAM（Segment Anything 轻量版）把鸟精确分割出来——站在人肩膀上、手指上的鸟也能和人分开；
- **挑片段**（视频）：逐帧跟踪，只留下"鸟清楚、整只在画面里、没被挡住"的连续片段（1～4 秒），对齐防抖，
  判断头朝哪边；横向移动多的归为"溜达"，其余归为"发呆"；
- 处理不了时会说原因，比如"鸟大部分时间被挡住"、"这只看起来像虎皮鹦鹉"。

怎么拍效果最好：
- 鸟**整只**在画面里，占画面三分之一以上；别用手握着、别隔着笼子拍；
- 镜头稳一点，每个动作拍 2～3 秒；背景越简单越好；
- 照片只能做成"一帧 + 整体跳动"，视频才有真的动作。

处理记录在 `assets/real/.imported.json`，原文件不会被改动。想全部重来：右键 → 真实素材 → 重新处理全部素材。
手动导入也可以：`~/Library/Application\ Support/parrot-pet/venv/bin/python tools/import_media.py 视频.mp4 --species roseicollis`

## AI 生成动作

只有一张鸟的照片也能做出会动的真实形象：右键 → AI 生成动作 → 用一张照片生成动作…

1. 第一次用先在「设置（服务、密钥）」里选生成服务、填 API Key（只存在本机用户目录的 `videogen.json`，不进代码仓库）。
2. 选一张照片后，会先把鸟抠出来放到纯色背景上（照片里的人和背景不会发出去），再按动作生成 5 秒的短视频。
3. 生成前会弹窗说明要生成几段、大概多少钱；可以选「全部」或「只生成核心 4 段」（发呆、理毛、吃东西、睡觉）。
4. 生成好的视频存成 `<鸟种>/<动作>.ai-<时间>.mp4`，自动抠图导入到对应动作。

目前支持的服务：
- **阿里云百炼（通义万相图生视频）**：默认 `wan2.6-i2v-flash`、720P、无声，官方价约 0.15 元/秒，一段 5 秒约 0.75 元。
- **滴水模型中心**：已预留，等视频接口文档接入。

提示词在 `src/aiprompts.js`，每个动作一句，各鸟种的习性动作单独写；生成队列在 `src/videogen.js`。
手动丢进素材文件夹的视频，文件名里带动作名（如 `理毛.mp4`、`吃瓜子.mov`、`玄凤国歌.mp4`）也会自动归到对应动作。

## 开发

- `src/poses.html`：把所有动作的姿态排成一张表，调形状用（`python3 -m http.server -d src` 后打开）。
- 直接在浏览器打开 `src/index.html` 会进入"模拟模式"：整个网页当屏幕，左上角有动作按钮。
- `PET_DEBUG=1 npm start`：渲染进程日志打到终端，每 3 秒存一张窗口截图到 `/tmp/parrot_pet_*.png`。

## 文件

```
main.js            Electron 主进程：透明置顶窗口、菜单、托盘、读素材
src/catalog.js     鸟种、习性、形象、动作、大小清单
src/parrot.js      插画风卡通鹦鹉（SVG 部件 + 转轴，各鸟种外形参数）
src/actions.js     每个动作的姿态函数
src/pet.js         状态机、物理（重力、反弹）、鼠标交互
src/real.js        真实形象播放器
src/sound.js       WebAudio 合成叫声
tools/             抽帧、找鸟（birdcut.swift）、抠鸟（birdseg.py）、导入（import_media.py）、一键安装（setup.sh）
src/importer.js    盯素材文件夹、排队自动导入（按文件名认动作）
src/videogen.js    AI 生成动作：照片预处理、提交生成、轮询、下载
src/aiprompts.js   AI 生成用的各动作提示词
```
