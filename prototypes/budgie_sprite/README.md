# 虎皮图片部件原型

Gemini 画的水彩部件（`parts/`，原图在 `source/`）挂到桌宠现有的骨架上，用 `src/actions.js` 里的动作驱动。

- 浏览器打开 `proto.html?play=idle,walk,eat,preen,sleep,look!,stretch,fly` 循环播放（动作名后加 `!` 是正脸）
- 换角度（侧脸 / 3/4 / 正脸 / 扭到背后）、张开的翅膀、炸毛的身子都用交叉淡入切换
- 理毛时整块换成 `bust.png`（头、脖子、肩膀连着画），避免断开；脖子底下垫一层同色晕染
- `cut.py` / `cut2.py`：去掉白纸底或"假透明"格子底，切出部件

已知局限：部件是硬纸片，不会变形，大幅低头、转头时脖子仍不够自然。之后打算用 Rive 做网格变形。
